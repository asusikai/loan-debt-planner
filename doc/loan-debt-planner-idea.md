# 대출 & 빚 관리 웹앱 기획안 (MVP)

## 1) 어떤 유저가 사용할 것인지
- 사회초년생(23~32세) 중, 2개 이상의 채무(신용대출, 마이너스통장, 카드 리볼빙 등)를 동시에 보유한 사용자
- 월 상환 가능 금액은 제한되어 있지만, 어떤 빚부터 갚아야 유리한지 판단이 어려운 사용자

## 2) 해당 유저가 겪는 문제
- 채무마다 금리, 잔액, 최소납입액, 만기가 달라 상환 우선순위를 정하기 어렵다.
- "매달 갚고는 있지만" 실제로 총이자를 줄이는 방식으로 갚고 있는지 알기 어렵다.
- 중도상환수수료/기간 조건을 고려하지 않아 비효율적인 상환 결정을 내리기 쉽다.

## 3) 해당 문제를 어떻게 해결할 것인지
- 사용자가 대출 정보를 직접 입력하면, 앱이 상환 전략을 시뮬레이션해 비교한다.
  - 전략 A: 고금리 우선 상환(Avalanche)
  - 전략 B: 소액잔액 우선 상환(Snowball)
- 두 전략의 결과를 수치로 제공한다.
  - 총 이자 비용
  - 예상 완납 시점
  - 월별 상환 계획표
- 사용자는 "월 추가 상환 가능 금액"을 바꿔보며 가장 현실적인 상환 플랜을 선택할 수 있다.

## MVP 핵심 기능
- 채무 등록/수정/삭제
- 상환 전략 2가지 비교 결과 제공
- 월별 상환 스케줄 표 제공

## 주요 엣지 케이스
- 월 상환 가능 금액이 최소납입액 합계보다 작은 경우: 경고 및 우선순위 재조정 안내
- 금리가 0%인 채무가 있는 경우: 이자 절감이 아닌 만기/현금흐름 기준으로 정렬
- 중도상환수수료가 있는 경우: 추가상환 이득(절감이자)과 수수료를 함께 계산
