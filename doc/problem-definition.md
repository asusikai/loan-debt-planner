# 문제 정의 문서 (평가 40점 대응)

- 프로젝트명: DebtPilot - 대출 상환 전략 플래너
- 과제 주제: 1) 대출 & 빚 관리
- 작성일: 2026-02-10

## 1. 해결하려는 문제 (문제의 구체성 15점)
### 1-1. 문제 한 줄 정의
다중 채무를 가진 사회초년생이 제한된 월 상환 가능 금액 안에서 어떤 채무를 먼저 갚아야 총이자를 최소화할 수 있는지 판단하기 어렵다.

### 1-2. 현재 불편/페인포인트
- 신용대출, 마이너스통장, 카드 리볼빙 등 채무별 금리와 상환 조건이 달라 우선순위 결정을 직관에 의존한다.
- 최소납입액만 맞추는 방식으로 상환하다 보니 총이자가 늘어나고 완납 시점이 늦어진다.
- 중도상환수수료, 만기 잔여 개월 수, 월 가용 현금흐름을 함께 고려한 비교 도구가 없어 의사결정 피로가 크다.

### 1-3. 왜 이 문제를 선택했는가
- 배경: 사회초년생은 소득이 제한적인 시기에 다중 채무를 보유하는 경우가 많고, 상환 전략이 재무 건전성에 큰 영향을 준다.
- 중요성: 잘못된 상환 순서는 장기간 누적 이자를 증가시켜 실질 손실을 만든다.
- 기대효과: 사용자 입력만으로 상환 전략별 총비용과 기간을 비교해 더 합리적인 상환 결정을 돕는다.

### 1-4. 측정 가능한 목표 (KPI)
- KPI 1: 사용자 기존 상환 순서 대비 총이자 8% 이상 절감 가능한 전략 제시
- KPI 2: 완납 예상 시점 3개월 이상 단축 가능한 시나리오 제시
- KPI 3: 채무 입력 후 전략 비교 결과 확인까지 3분 이내 완료

## 2. 범위 설정 (적절성 10점)
### 2-1. 핵심 기능 (Must)
1. 채무 입력/수정/삭제 (잔액, 연이율, 최소납입액, 만기 잔여 개월 수, 중도상환수수료)
2. 상환 전략 비교 (Avalanche: 고금리 우선, Snowball: 소액잔액 우선)
3. 결과 리포트 (총이자, 완납 예상 시점, 월별 상환 계획표)

### 2-2. 부가 기능 (Should/Could)
- 월 추가상환 금액 슬라이더로 즉시 재계산
- 전략별 핵심 차이 요약 카드(총이자 차이, 기간 차이)
- 시나리오 저장(기기 로컬 스토리지)

### 2-3. 이번 과제에서 제외하는 범위 (Won't)
- 외부 금융 API 연동 및 자동 데이터 수집
- 계정 시스템/로그인/클라우드 동기화
- 실제 금융상품 추천 및 법률/세무 자문 기능

### 2-4. 시간 제약 기반 우선순위
- Day 1: 입력 폼, 상환 계산 엔진, 전략 비교 결과(핵심 수치)
- Day 2: 월별 상환표, 엣지 케이스 처리, 문서화(README/기획서)

## 3. 대상 사용자 및 시나리오 (10점)
### 3-1. 대상 사용자 정의
- 페르소나 A: 27세 직장인, 월 실수령 290만원, 신용대출 2건 + 카드 리볼빙 1건 보유, 월 상환 여력 70만원
- 페르소나 B: 31세 프리랜서, 수입 변동성 높음, 마이너스통장 + 할부성 대출 보유, 월 상환액 변동 관리 필요

### 3-2. 대표 사용자 여정
1. 사용자가 보유 채무 정보(잔액/금리/최소납입액/수수료)를 입력한다.
2. 월 상환 가능 금액과 추가 상환 가능 금액을 설정한다.
3. 앱이 Avalanche와 Snowball 전략을 각각 시뮬레이션한다.
4. 총이자와 완납 시점을 비교해 사용자 목표(비용 최소/기간 단축)에 맞는 전략을 선택한다.
5. 월별 상환 계획표를 확인하고 다음 달 실행 계획을 확정한다.

### 3-3. 사용자 의사결정 포인트
- 어떤 전략이 총 이자 비용을 더 낮추는가?
- 완납까지 걸리는 기간 차이가 실제로 의미 있는 수준인가?
- 현재 월 현금흐름에서 연체 없이 실행 가능한가?

## 4. 엣지 케이스 및 처리 방안 (5점)
| 케이스 | 위험 | 처리 방안 |
|---|---|---|
| 월 상환 가능액 < 최소납입액 합계 | 연체 및 신용점수 하락 위험 | 경고 배너 표시, 추가상환 금액 0으로 강제, 최소납입액 우선 배분 |
| 0% 금리 채무 존재 | 우선순위 판단 왜곡 | 이자 기준 정렬에서 제외하고 만기 임박 순 보조 정렬 |
| 중도상환수수료 존재 | 잘못된 조기상환 판단 | 절감이자 - 수수료 순효과를 계산해 플러스일 때만 조기상환 추천 |
| 입력값 누락/음수/비정상 값 | 계산 오류 및 신뢰도 하락 | 실시간 유효성 검사, 제출 버튼 비활성화, 항목별 오류 메시지 |
| 동일 조건으로 전략 결과가 거의 동일 | 선택 피로 | 동률 안내 및 사용자 목표(비용/기간) 기준으로 추천 문구 제공 |

## 5. 성공 기준 요약
- 문제를 한 문장으로 정의하고, 목표를 정량 KPI로 제시한다.
- 핵심 기능과 제외 범위를 명확히 구분해 2일 내 구현 가능한 범위로 제한한다.
- 사용자 여정이 실제 상환 의사결정 흐름과 일치한다.
- 주요 예외 상황에 대한 처리 방안을 문서와 UI 동작으로 확인 가능하다.

## 6. 검증 계획 (결과물 판단력 연결)
- 계산 정확성 검증: 수기 계산 샘플 5건(단일 채무, 다중 채무, 수수료 포함 케이스)과 결과 비교
- 회귀 확인: 핵심 계산 함수 테스트(전략별 총이자, 완납월, 월별 잔액 감소) 작성
- 신뢰성 확인: 극단값 테스트(고금리, 장기상환, 최소납입액 부족) 수행
