# 문제 정의 문서 (코드베이스 동기화)

## 0. 문서 메타
- 프로젝트명: DebtPilot - 대출 상환 전략 플래너
- 과제 주제: 1) 대출 & 빚 관리
- 작성일: 2026-02-12
- 작성자: 안동준

## 1. 해결하려는 문제

### 1-1. 문제 한 줄 정의
다중 채무 사용자가 제한된 추가 상환 금액을 어떤 채무에 우선 배분해야 총비용을 줄일 수 있는지 판단하기 어렵다.

### 1-2. 현재 불편/페인포인트
- 채무별 금리, 상환 방식(원리금균등/원금균등/원금만기일시), 만기, 거치 조건이 달라 우선순위 판단이 어렵다.
- 중도상환수수료를 고려하지 않으면 추가 상환이 항상 유리하다고 오판할 수 있다.
- 실행 가능한 월별 상환 계획이 없으면 계산 결과를 실제 행동으로 옮기기 어렵다.

### 1-3. 선택 근거
- 상환 순서 결정은 총이자와 완납 기간에 직접 영향을 준다.
- 사용자에게 필요한 것은 "복잡한 계산" 자체보다 "비교 가능한 의사결정 정보"다.
- 코드베이스는 전략 비교, 수수료 반영, 월별표까지 한 흐름으로 제공하도록 설계되어 있다.

### 1-4. 측정 가능한 목표 (KPI)
- KPI 1: 입력 후 전략 비교 결과 확인까지 3분 이내
- KPI 2: 동일 입력에서 전략별 총이자/완납개월 차이 확인 가능
- KPI 3: 수수료 포함 시 순절감액(`netSavings`)까지 제공

## 2. 범위 설정

### 2-1. 핵심 기능 (Must)
1. 채무 입력/수정/삭제
   - 입력: 채무명, 잔액, 연이율, 상환 방식, 만기, 거치 기간, 중도상환수수료율
2. 전략 시뮬레이션 비교
   - Avalanche(고금리 우선), Snowball(소액잔액 우선)
3. 결과 리포트
   - 총이자, 총수수료, 순절감액, 완납 예상 월, 월별 상환 계획표

### 2-2. 부가 기능 (Should/Could)
- LocalStorage 기반 입력 복원
- 추천 전략 자동 선택(총이자 기준)
- 상태 초기화, 삭제 확인, 토스트/에러 모달

### 2-3. 제외 범위 (Won't)
- 외부 금융 API 연동
- 로그인/클라우드 동기화
- 금융상품 추천 및 법률/세무 자문

## 3. 대상 사용자 및 시나리오

### 3-1. 대상 사용자
- 2개 이상 채무를 관리 중인 사용자
- 월별 추가 상환 여력이 있어 배분 최적화가 필요한 사용자

### 3-2. 대표 사용자 여정
1. 채무 정보를 입력한다.
2. 추가 상환 금액을 설정한다.
3. Avalanche/Snowball 전략을 계산한다.
4. 총이자/수수료/순절감액/완납개월을 비교한다.
5. 월별표를 확인하고 실행 계획을 정한다.

## 4. 엣지 케이스 및 처리 방안
| 케이스 | 위험 | 처리 방안 |
|---|---|---|
| 채무 0건에서 계산 시도 | 잘못된 시뮬레이션 요청 | 계산 중단 + 경고 메시지 |
| `bullet`인데 만기 미입력 | 도메인 규칙 위반 | 폼/API 스키마 검증 실패 처리 |
| `bullet`인데 거치 기간 입력 | 규칙 위반 | 입력 차단 및 오류 메시지 표시 |
| `graceMonths >= maturityMonths` | 상환 스케줄 모순 | 검증 실패 처리 |
| 손상된 LocalStorage 값 | 초기 로딩 실패 | 경고 후 기본 상태로 복원 |
| 장기 미완납 시나리오 | 무한 루프 위험 | 1200개월 제한 + 예외 발생 |

## 5. 성공 기준 요약
- 전략 비교가 총이자뿐 아니라 수수료/순절감액까지 포함한다.
- 상환 방식 제약(만기/거치)이 검증 단계에서 강제된다.
- 월별 상환표를 통해 계산 결과를 실행 계획으로 전환할 수 있다.
