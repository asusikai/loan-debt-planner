# 요구사항 정의서

## 1. 개요
- 서비스명: DebtPilot
- 도메인: 개인 금융(대출/빚 관리)
- 목적: 다중 채무 상환 전략을 비교해 총비용과 상환 기간을 줄이기

## 2. 대상 사용자
- 사회초년생(23~32세)
- 2개 이상 채무 보유자(신용대출, 마이너스통장, 카드 리볼빙 등)
- 월 상환 가능 금액이 고정 또는 제한적인 사용자

## 3. 기능 요구사항

### 3.1 필수 기능(Must)
1. 채무 등록/수정/삭제
   - 입력 항목: 채무명, 잔액, 연이율, 최소납입액, 만기 잔여 개월 수(선택), 중도상환수수료율(선택)
2. 월 상환 가능 금액 설정
3. 상환 전략 시뮬레이션
   - Avalanche: 고금리 우선 상환
   - Snowball: 소액잔액 우선 상환
4. 전략 비교 결과 제공
   - 총이자
   - 완납 예상 시점
   - 총 상환 개월 수
5. 월별 상환 계획표 제공

### 3.2 선택 기능(Should)
1. 월 추가상환 금액 슬라이더
2. 전략 추천 문구(비용 최소/기간 단축 기준)
3. 입력값 로컬 저장(LocalStorage)

### 3.3 제외 기능(Won't)
1. 외부 금융 API 연동
2. 로그인/회원가입
3. 실제 금융상품 추천 및 법률/세무 자문

## 4. 비기능 요구사항
- 정확성: 동일 입력에 대해 항상 동일 결과를 반환
- 성능: 20개 채무 기준 시뮬레이션 1초 내 응답 목표
- 사용성: 핵심 결과(총이자/완납시점)를 첫 화면에서 확인 가능
- 신뢰성: 잘못된 입력 차단 및 명확한 오류 메시지 제공

## 5. 입력 검증 규칙
- 잔액, 연이율, 최소납입액, 월 상환 가능 금액은 0 이상
- 채무가 1개 이상 있어야 시뮬레이션 가능
- 월 상환 가능 금액 >= 최소납입액 합계여야 정상 시뮬레이션

## 6. 수용 기준(AC)
1. 사용자가 채무 3개를 입력하면 두 전략 결과가 모두 계산되어야 한다.
2. 월 상환 가능 금액이 최소납입액 합계보다 작으면 계산 대신 경고를 표시해야 한다.
3. 결과 화면에서 총이자와 완납 시점을 전략별로 동시에 확인할 수 있어야 한다.
4. 월별 상환 계획표에서 월별 잔액 감소를 확인할 수 있어야 한다.
