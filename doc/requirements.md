# 요구사항 정의서 (코드베이스 기준)

## 1. 개요
- 서비스명: DebtPilot
- 도메인: 개인 금융(대출/빚 관리)
- 목적: 다중 채무 상환 전략(Avalanche/Snowball)을 비교해 총이자와 상환 기간을 개선

## 2. 대상 사용자
- 다중 채무(2건 이상)를 보유한 사용자
- 상환 방식/만기/수수료가 섞여 있어 우선순위 판단이 어려운 사용자
- 추가 상환 금액을 조정해 시뮬레이션하려는 사용자

## 3. 기능 요구사항

### 3.1 필수 기능 (Must)
1. 채무 등록/수정/삭제
   - 입력 항목: 채무명, 잔액, 연이율, 상환 방식, 만기 잔여 개월 수(조건부), 거치 기간(선택), 중도상환수수료율(선택)
2. 추가 상환 금액 설정
   - 월 필수 납입액은 엔진에서 자동 계산
3. 상환 전략 시뮬레이션
   - Avalanche: 고금리 우선(0% 금리는 후순위)
   - Snowball: 소액잔액 우선
4. 전략 비교 결과 제공
   - 총이자(`totalInterest`)
   - 총수수료(`totalFeesPaid`)
   - 순절감액(`netSavings`)
   - 완납 개월 수/완납 월
5. 월별 상환 계획표 제공
   - 월별 납입액, 이자액, 원금상환액, 잔액

### 3.2 선택 기능 (Should)
1. LocalStorage 저장/복원(채무, 추가 상환 입력)
2. 추천 전략 자동 선택(총이자 기준)
3. 에러 모달/토스트/삭제 확인 등 UX 보조

### 3.3 제외 기능 (Won't)
1. 외부 금융 API 연동
2. 로그인/회원가입
3. 금융상품 추천 및 법률/세무 자문

## 4. 비기능 요구사항
- 정확성: 동일 입력 시 동일 결과를 반환하는 결정적 계산
- 안정성: 저장소 손상/예외 입력에서도 앱이 종료되지 않고 복구 가능한 피드백 제공
- 사용성: 결과 카드와 월별표를 같은 화면에서 확인 가능
- 테스트성: 핵심 엔진/유틸 단위 테스트와 E2E 흐름 검증 유지

## 5. 입력 검증 규칙
- 공통: 채무는 1개 이상, 추가 상환 금액은 0 이상
- 채무: 잔액은 1 이상, 연이율은 0 이상
- `bullet` 상환 방식: 만기 잔여 개월 수 필수, 거치 기간 입력 불가
- 거치 기간: 0 이상, 만기 존재 시 `graceMonths < maturityMonths`
- 중도상환수수료율: 0 이상

## 6. 수용 기준 (AC)
1. 채무 2건 이상 입력 시 Avalanche/Snowball 결과가 모두 계산된다.
2. 전략 결과에서 총이자/총수수료/순절감액/완납 개월 수를 동시에 확인할 수 있다.
3. 월별 상환 계획표에서 월별 잔액 감소가 확인된다.
4. 잘못된 입력(예: bullet 만기 누락, 거치>=만기)은 제출 단계에서 차단된다.
5. 손상된 LocalStorage가 있어도 메인 화면은 정상 렌더링된다.
