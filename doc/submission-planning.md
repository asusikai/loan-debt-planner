# DebtPilot 기획서 (제출용)

## 1. 프로젝트 개요
- 과제 주제: 1) 대출 & 빚 관리
- 서비스명: DebtPilot
- 목표: 다중 채무 사용자가 상환 전략(Avalanche/Snowball)을 비교해 총비용과 완납 기간을 합리적으로 결정하도록 지원

## 2. 문제 정의

### 2.1 해결하려는 문제
다중 채무 상황에서는 금리만으로 우선순위를 정하기 어렵다. 상환 방식, 만기, 거치, 수수료까지 함께 고려해야 하지만 이를 수작업으로 계산하기 어렵다.

### 2.2 선택 이유
- 사용자 입장에서 실제로 어려운 지점은 "계산"보다 "의사결정"이다.
- 잘못된 상환 우선순위는 총이자 증가와 완납 지연으로 이어진다.
- 따라서 비교 가능한 결과와 실행 가능한 월별 계획을 함께 제공하는 도구가 필요하다.

### 2.3 핵심 가설
- 전략 비교 결과를 명확한 지표(총이자, 총수수료, 순절감액, 완납개월)로 제공하면 의사결정 속도와 신뢰도가 높아진다.

## 3. 대상 사용자
- 2건 이상 채무를 가진 사용자
- 월별 추가 상환 여력이 있어 우선순위 최적화가 필요한 사용자
- 금융 계산 지식이 높지 않아도 직관적 비교를 원하는 사용자

## 4. 사용자 시나리오
1. 사용자가 채무 정보를 입력한다.
2. 추가 상환 금액을 입력한다.
3. 전략 비교를 실행한다.
4. 추천 전략과 지표를 확인한다.
5. 월별 상환표를 기반으로 실제 실행 계획을 확정한다.

## 5. 범위 설정

### 5.1 핵심 기능 (Must)
- 채무 등록/수정/삭제
- 전략 비교(Avalanche, Snowball)
- 핵심 지표 제공(총이자, 총수수료, 순절감액, 완납개월, 완납월)
- 월별 상환표 제공

### 5.2 부가 기능 (Should)
- 로컬 저장/복원
- 전략 자동 추천
- 상태 초기화/에러 모달/토스트

### 5.3 제외 범위 (Won't)
- 로그인/회원
- 외부 금융 API
- 금융상품 추천 및 자문 기능

## 6. 엣지 케이스 설계
- 채무가 없는 상태에서 계산 시도
- bullet 상환에서 만기 미입력
- bullet 상환에서 거치 기간 입력
- 거치 기간이 만기 이상
- LocalStorage 데이터 손상
- 장기 미완납 시나리오

## 7. 성공 기준 (KPI)
- 입력 후 결과 확인까지 3분 이내
- 전략별 핵심 지표를 한 화면에서 비교 가능
- 월별 상환 계획이 실제 실행 수준으로 해석 가능

## 8. 산출물
- 기획/개발 문서(마크다운)
- 동작 웹앱(Next.js)
- 테스트 코드(Vitest, Playwright)

## 9. 평가 기준 대응 (문제 정의 40점 중심)

| 평가 역량 | 배점 | 본 문서 대응 방식 | 증빙 위치 |
|---|---:|---|---|
| 문제 정의 능력 | 40 | 해결 문제, 범위, 사용자 시나리오, 엣지 케이스를 별도 명시 | 본 문서 2~6장 |
| 결과물 판단력 | 25 | 결과 지표(총이자/수수료/순절감액/완납개월) 중심 의사결정 구조 명시 | 본 문서 2.3, 5.1 |
| 반복적 개선 능력 | 20 | 우선순위 기반 구현 범위 설정(핵심-부가-제외) | 본 문서 5장 |
| 맥락 관리 능력 | 15 | 문제-기능-검증 흐름을 문서 구조로 고정 | 본 문서 전체 |

### 9.1 문제 정의 구체성 (15점) 대응
- 한 줄 문제 정의를 "추가 상환 배분 의사결정"으로 한정해 모호성 제거
- 결과 비교 지표를 정량 항목으로 고정(총이자, 총수수료, 순절감액, 완납개월)

### 9.2 범위 설정 적절성 (10점) 대응
- Must/Should/Won't를 분리해 과제 기간 내 구현 가능 범위로 제한
- 인증/외부 API/자문 기능 등 확장 요소를 명시적으로 제외

### 9.3 사용자 시나리오 (10점) 대응
- 입력 -> 계산 -> 비교 -> 실행계획 확정의 실제 사용 순서 정의
- 결과 확인 이후 "재입력/재계산" 반복 루프를 전제

### 9.4 엣지 케이스 (5점) 대응
- 도메인 규칙 위반(`bullet` 만기/거치 제약)과 데이터 손상(LocalStorage) 케이스를 분리 정의
- 장기 미완납 시나리오를 별도 리스크로 관리
