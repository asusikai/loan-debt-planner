# AI 협업 로그 (Task 11~15)

## 개요

- 목적: 구현 과정에서 AI 활용 방식과 검증 결과를 기록해 재현 가능한 협업 패턴 확립
- 범위: 수수료 계산, 정렬 로직, 정밀도/테스트, 훅 의존성 정비

## 1) 프롬프트 기록

- Task 11(수수료): 수수료 계산 방식(슬라이딩/고정), `netSavings` 반영 규칙, 경계값 테스트 생성 요청
- Task 12(정렬): 0% 금리 후순위, 만기 보조 정렬 기준, SortProvider 분리와 테스트 확장 요청
- Task 15(훅): `useCallback` 적용 범위와 기능형 업데이트 전환으로 의존성 단순화 요청

## 2) AI 제안 검증 사례

- 사례 A: 수수료 반영 시 원금 감소 처리 방식 검증
  - 초기 제안: 수수료를 원금 감소량과 직접 결합하는 접근
  - 검증 결과: 기존 엔진 회계 모델과 불일치 가능성 확인
  - 조치: 원금 감소/수수료 집계를 분리하고 회귀 테스트로 검증

- 사례 B: 장기 상환 회귀 시나리오 범위 검증
  - 초기 제안: 소수 시나리오 단일 검증
  - 검증 결과: 장기/대규모 조합에서 누락 가능성 확인
  - 조치: 시드 기반 매트릭스 테스트로 범위 확장

## 3) 수정 근거(Rationale)

- 수수료 처리 로직은 "지표 일관성"을 최우선 기준으로 채택
  - 이유: 전략 비교 카드에서 총이자/수수료/순절감액의 해석 가능성 확보 필요
- 정렬 로직은 "설명 가능한 우선순위" 기준으로 보정
  - 이유: 0% 금리와 만기 임박 케이스에서 사용자 관점 예측 가능성 필요
- 테스트는 "회귀 방지"를 기준으로 매트릭스 범위 확장
  - 이유: 단일 시나리오 통과만으로는 장기 상환 리스크를 포착하기 어려움
